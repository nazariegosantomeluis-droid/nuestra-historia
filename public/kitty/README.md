# Carpeta `public/kitty/`

Coloca aquí las 7 imágenes de Hello Kitty, con estos nombres exactos:

```
kitty01.png
kitty02.png
kitty03.png
kitty04.png
kitty05.png
kitty06.png
kitty07.png
```

- Formatos aceptados: **PNG, JPG o WebP** (si usas otra extensión, actualiza
  la ruta correspondiente en `src/data/relationship.ts`, dentro de
  `kittyHunt.kittyImages`).
- Si la imagen tiene fondo transparente (PNG), se integrará mejor en las
  tarjetas decorativas.
- Si no tiene fondo transparente, no pasa nada: las tarjetas ya tienen su
  propio fondo decorativo detrás de cada imagen.
- Mientras no coloques un archivo, la aplicación muestra automáticamente un
  pequeño marcador de posición (silueta) en su lugar — no se rompe nada.

Ver `CONTENT_GUIDE.md` en la raíz del proyecto, sección 8, para más detalle.
