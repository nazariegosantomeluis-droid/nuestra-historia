# Carpeta `public/memories/`

Coloca aquí las fotografías de la relación que se usan en los 7 recuerdos
del Nivel 2, con estos nombres (o los que prefieras, siempre que actualices
la ruta en `src/data/relationship.ts`):

```
photo01.jpg
photo02.jpg
photo03.jpg
photo04.jpg
photo05.jpg
photo06.jpg
photo07.jpg
```

- Formatos aceptados: JPG, PNG o WebP.
- Si un recuerdo no tiene fotografía, deja `photo: null` en
  `src/data/relationship.ts` para ese recuerdo.
- Si el archivo no existe todavía, el marco de la fotografía simplemente no
  se muestra (no aparece un ícono de imagen rota).

Ver `CONTENT_GUIDE.md` en la raíz del proyecto, sección 7, para más detalle.
