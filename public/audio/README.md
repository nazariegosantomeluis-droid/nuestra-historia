# Carpeta `public/audio/`

Coloca aquí, si quieres, una canción con el nombre:

```
music.mp3
```

- No se reproduce automáticamente: aparece un botón discreto (esquina
  inferior derecha) para reproducirla o pausarla.
- Si no colocas ningún archivo, el botón simplemente desaparece — no rompe
  la experiencia.

Ver `CONTENT_GUIDE.md` en la raíz del proyecto, sección 10, para más detalle.
